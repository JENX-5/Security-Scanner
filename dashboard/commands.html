5 Terminal Commands to Induce & Fix Vulnerabilities

Copy and run these commands in your terminal to create intentional misconfigurations in your AWS account. After running each command, glance at the sticky header above and click Run scan to watch the Security Score drop in real time. Switch to the Fix & Remediate tab to resolve the issue and watch your score recover back to 100.

Sandbox only. These scenarios deliberately create exposed or unencrypted AWS resources. Use a dedicated test account, never production, and run the cleanup command when finished.

Prerequisite in your Terminal: export AWS_PROFILE=scanner AWS_REGION=eu-north-1

1. Expose SSH Port 22 to the World

Creates a demo security group with unrestricted ingress on TCP port 22 (0.0.0.0/0).

High Score: 100 → 82 (-18 pts)
TERMINAL · AWS CLI 
aws ec2 create-security-group --group-name demo-scanner-sg --description "Compliance scanner demo group" --region eu-north-1 --profile scanner 2>/dev/null || true
aws ec2 authorize-security-group-ingress --group-name demo-scanner-sg --protocol tcp --port 22 --cidr 0.0.0.0/0 --region eu-north-1 --profile scanner
TERMINAL · AWS CLI REMEDIATION 
aws ec2 revoke-security-group-ingress --group-name demo-scanner-sg --protocol tcp --port 22 --cidr 0.0.0.0/0 --region eu-north-1 --profile scanner

3. Provision Unencrypted EBS Storage Volume

Creates a 1 GiB Elastic Block Store volume without encryption at rest enabled.

High Score: 64 → 46 (-18 pts)
TERMINAL · AWS CLI 
aws ec2 create-volume --availability-zone eu-north-1a --size 1 --volume-type gp3 --no-encrypted --tag-specifications 'ResourceType=volume,Tags=[{Key=Name,Value=demo-unencrypted-vol-1}]' --region eu-north-1 --profile scanner

5. Expose S3 Bucket Policy Publicly

Creates an S3 bucket with Block Public Access disabled and an open public read policy.

Critical Score: 28 → 0 (-30 pts)
TERMINAL · AWS CLI 
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text --profile scanner)
aws s3api create-bucket --bucket "demo-public-bucket-${ACCOUNT_ID}" --region eu-north-1 --create-bucket-configuration LocationConstraint=eu-north-1 --profile scanner 2>/dev/null || true
aws s3api put-public-access-block --bucket "demo-public-bucket-${ACCOUNT_ID}" --public-access-block-configuration "BlockPublicAcls=false,IgnorePublicAcls=false,BlockPublicPolicy=false,RestrictPublicBuckets=false" --profile scanner
aws s3api put-bucket-policy --bucket "demo-public-bucket-${ACCOUNT_ID}" --policy "{\"Version\":\"2012-10-17\",\"Statement\":[{\"Sid\":\"PublicRead\",\"Effect\":\"Allow\",\"Principal\":\"*\",\"Action\":\"s3:GetObject\",\"Resource\":\"arn:aws:s3:::demo-public-bucket-${ACCOUNT_ID}/*\"}]}" --profile scanner
TERMINAL · AWS CLI REMEDIATION 
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text --profile scanner)
aws s3 rb "s3://demo-public-bucket-${ACCOUNT_ID}" --force --profile scanner
